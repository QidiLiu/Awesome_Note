# Awesome Note

A simple public notes repo. I want to share all the excellent notes that are valuable here.

README.md (in root) is the only index for this repo. All docs and its translation versions are saved in doc/. The titles are listed here with markdown links to the original doc, like `[<author> - <title>](doc/<author>-<title>.md)` or `[<author> - <title> - 中文](doc/<author>-<title_CN>.md)`. And the README.md was organized with a set of topic categories, so that the readers can find the doc faster and click into the doc directly on GitHub.
