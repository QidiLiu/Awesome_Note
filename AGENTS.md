# AGENTS.md

A public, curated collection of notes. README.md is the sole index; all notes live in `doc/`.

## File naming

- Original: `doc/<Author>-<Title_with_underscores_for_spaces>.md`
- Chinese translation: `doc/<Author>-<Title_with_underscores_for_spaces>_CN.md`

## Adding a note

When adding a new note:
1. Place the markdown file in `doc/` following the naming convention above.
2. Add a link to README.md under the appropriate topic category section, using the format:
   - `[<Author> - <Title>](doc/<filename>.md)`
   - `[<Author> - <Title> - 中文](doc/<filename>_CN.md)` for translations.
3. If a matching category section does not exist, create one (a `##` heading) in README.md. Keep sections alphabetically ordered.
